# picturereader —— 图片直接读（本地命令版，MCP 已废弃）

**唯一用法（Bash 直接执行，无需任何配置/发现/连接）：**

```bash
imgread <图片绝对路径>          # 证据层：结构+形状+OCR+结论，一次全出
imgvlm <图片绝对路径> <问题>    # 语义层：证据 + 本地视觉外援(Qwen3-VL)回答"这是什么"
```

## 铁律
- 用户提到图片、截图、"看一下这张图/读图/识别/视觉验证" → **立即执行上面的命令**，禁止说"我看不了图"
- **禁止去找 MCP server、禁止 ps/netstat 探测、禁止手写 JSON-RPC**——命令就在 PATH 上，直接跑
- 精细模式：`imgread 路径 shapes`（图形/方块坐标）、`ocr`（文字）、`sample x y w h`（区域采样）
- 游戏/UI 渲染验收：`imgread 截图.png` 看[形状][文字]区，配合 `imgvlm 截图.png 渲染正常吗` 做语义判断
- 输出全中文带坐标，就是文字证据，直接引用下结论
- 纯本地 CPU/GPU1，不联网，不会失败；失败只有路径写错一种可能
